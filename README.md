# W6-32 Information

This repository provides information which caan be used for protein design work to generate a nanobody which mimics the qualities of the W6/32 antibody, but without the steric clashes involving the light chain and the linkers in the Single Chain Trimer.

# Use of AI in this project

One aim of this project is to understand how Agentic AI can be used in scientific research. The project was initially proposed as part of the AI Scientists call by ARIA but was sadly not funded. 

One aim of this repository, aside from the generation of data, is to show how Claude Code can build tools and compose them into analysis, keep a lab notebook and then generate conclusions. 

Minimal intervention with Claude Code was performed during the generation of tools, their use and subsequent analysis. 

The initial experimental design is contained in the EXPERIMENTAL_DESIGN.md file. Claude Code's plan is in PLAN.md.

The lab notebook is the CHANGELOG.md file.
